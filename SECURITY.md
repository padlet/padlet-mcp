# Security

This repository contains documentation only. The Padlet MCP server at `https://mcp.padlet.com/`
is run by Padlet as part of the Padlet service.

## Reporting a vulnerability

Please report security issues in the Padlet MCP server, or in Padlet generally, privately by
email to [hello@padlet.com](mailto:hello@padlet.com), the contact listed in Padlet's
[security.txt](https://padlet.com/.well-known/security.txt). Include the steps to reproduce and
the impact you observed.

Please don't open a public GitHub issue for a security problem.

Padlet's security practices, certifications and bug bounty programme are described at
<https://legal.padlet.com/security>.
